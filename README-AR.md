# 🕊️ تطبيق زاجل شات (Zajil Chat) - سورس كود أندرويد الأصلي

**تطوير: سلامة تكنولوجي**  
**المطور: م/ بسام عبدالرقيب الشميري**  
**إصدار التطبيق:** 1.0.0 Native Kotlin  

---

تطبيق مراسلة أندرويد أصلي (Native Kotlin) يعمل دون إنترنت عبر اتصال Bluetooth RFCOMM المباشر بين الهواتف، مع تشفير AES-256-GCM عسكري وحظر الأجهزة ودعم الملاحظات الصوتية والصور والملفات.

## 🚀 كيفية بناء ملف APK وتثبيته على هاتفك مجاناً:

### الطريقة الأولى: البناء المجاني التلقائي عبر GitHub Actions (بدون تثبيت أي برامج!)
1. أنشئ حساباً مجانياً على GitHub إذا لم تكن مسجلاً.
2. أنشئ مستودعاً جديداً (New Repository) وقم برفع محتويات هذا المشروع.
3. توجه إلى تبويب **Actions**؛ سيعمل ملف `.github/workflows/build-apk.yml` تلقائياً لبناء التطبيق.
4. بمجرد الانتهاء (حوالي دقيقتين)، ستجد ملف **ZajilChat-Debug-APK** جاهزاً للتنزيل والتثبيت مباشرة على أي هاتف أندرويد!

### الطريقة الثانية: عبر Android Studio
1. افتح المشروع في أندرويد ستوديو (Open Project).
2. انتظر ثوانٍ لمزامنة Gradle.
3. اضغط على **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. ثبّت ملف `app-debug.apk` الناتج على هاتفك واستمتع بالتواصل المباشر أوفلاين!
